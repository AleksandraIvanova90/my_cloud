## Настройка React-проекта

1. Перейдите в папку **React-проекта** (**замените \*user\* на имя пользователя, под которым работаете на сервере**)
   ```
   cd /home/*user*/my_cloud/frontend
   ```
2. Установите зависимости проекта
   ```
   npm install
   ```
3. Соберите проект (**замените \*user\* на имя пользователя, под которым работаете на сервере**)
   ```
   npm run build
   sudo cp -r dist/* /home/*user*/my_cloud/frontend/dist/
   ```
4. Установите правильные права доступа (**замените \*user\* на имя пользователя, под которым работаете на сервере**)
   ```
   sudo chown -R www-data:www-data /home/*user*/my_cloud/frontend/dist
   sudo chmod -R 755 /home/*user*/my_cloud/frontend/dist
   ```
5. Создайте файл .env в корне React-проекта
   ```
   sudo nano .env
   ```
   *.env*
   ```
   REACT_APP_API_URL=http://ip_your_server/api/
   ```
   Сохраните файл и выйдите из него

Вы подготовили React-проект к развертыванию. Для развертывания и запуска вернитесь [***к Общим настройкам***](/README.md)
